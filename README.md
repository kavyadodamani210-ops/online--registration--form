Online Registration Form

Project Description

This project is a web-based Online Registration Form developed using PHP, MySQL, HTML, and CSS.

Technologies Used

- HTML
- CSS
- PHP
- MySQL
- XAMPP

Features

- User registration
- Form data validation
- Database connectivity
- Store registration details in MySQL

How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Import the project database using phpMyAdmin.
4. Copy the project folder into "C:\xampp\htdocs\".
5. Open the application using "http://localhost/your-project-folder/".

Project Purpose

Developed as part of the VTU academic project.
